# ViagemPE Chatbot

Repositório dividido em duas frentes:
- `src/`: Código fonte da aplicação Node.js (Equipe Dev).
- `infra/`, `docker/`, `.github/`: IaC, CI/CD e Conteinerização (Equipe DevOps).

## Como rodar localmente
1. Copie o `.env.example` para `.env` e insira suas chaves (ex: GEMINI_API_KEY).
2. Execute `docker-compose up` na pasta `docker/`.
